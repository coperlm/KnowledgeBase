    一、 第一类：必背概念题（共14个核心点，开袋即食“先理解后记忆”版）

    使用说明：记性不好千万不要逐字死背！每天早上花15分钟看懂每道题下面的【底层逻辑】，考场上无论是考单选题还是大题小问，顺着逻辑写出【采分关键词】即可拿满分。

    第1章（3题）

    1. 1-03 试从多个方面比较电路交换、报文交换和分组交换的主要优缺点。（官方大纲二(一)4）
    2. 【底层逻辑】：
      • 电路交换像“包专列火车”：通信前必须先建立专用的物理通路，通话期间哪怕双方不说话，别人也不能用这条路。所以实时性极高、无排队时延，但传突发计算机数据时线路利用率极低。
      • 报文交换像“搬运整座大山”：不切块，把几百MB的完整文件一口气发给下一跳路由器，路由器必须有巨大的磁盘把整座山存下来才能查表转发，导致转发时延极大。
      • 分组交换像“把大山切成标准快递盒”：分成小分组独立选路、边收边发（流水线）。

    3. 【采分关键词】：分组交换四大优点——①高效（动态分配传输带宽，逐段占用链路）；②灵活（每个分组独立选择转发路由）；③迅速（无需先建立连接即可发送，流水线转发时延小）；④可靠（分布式多路由网络生存性好）。缺点——①存储转发排队时延；②每个分组需携带额外控制首部开销（Overhead）。

    4. 1-06 简述互联网标准制定的几个阶段。（官方大纲一(一)3）

    5. 【底层逻辑】：随便写个想法叫“草案”，大家觉得行就变成“建议标准”（开始给RFC编号），全球大规模验证没问题就升为“正式标准”。

    6. 【采分关键词】：互联网草案（Internet Draft） \(\rightarrow\) 建议标准（Proposed Standard，从此阶段起成为 RFC 文档） \(\rightarrow\) 互联网标准（Internet Standard）。相关标准化组织：IETF（制定互联网RFC标准）、ISO（提出OSI七层模型）、IEEE（制定802局域网标准）。

    7. 1-21 协议与服务有何区别？有何关系？（官方大纲一(二)2，关联 2025-选1）

    8. 【底层逻辑】：你（本层）和你的上级（上层）之间是“上下级服务关系”；你和远方同级办事员（对等实体）之间是“按共同规矩办事的水平协议关系”。
    9. 【采分关键词】：①协议是“水平的”，是控制两个对等实体进行通信的规则集合（由语法、语义、同步三要素组成）；②服务是“垂直的”，是由下层向上层通过层间接口（SAP）提供的功能；③关系：在协议的控制下，两个对等实体间的通信使得本层能够向上一层提供服务，且下层协议对上层服务用户是透明（不可见）的。

    第2章（1题）

    1. 2-06 数据在信道中的传输速率受哪些因素的限制？信噪比能否任意提高？“比特/秒”和“码元/秒”有何区别？（官方大纲二(一)1,2，关联 2025-选2、2026-大1）
    2. 【底层逻辑】：影响车流量的就两件事——马路有多宽（带宽 \(W\)）、路上雾霾噪音有多大（信噪比 \(S/N\)）。码元是“一辆公交车”，比特是“车上坐的乘客”。
    3. 【采分关键词】：
      • 两大限制因素：①信道能够通过的频率范围（信道带宽 \(W\)），受奈氏准则限制，速率过高会产生严重的码间串扰；②信噪比（\(S/N\)），受香农公式 \(C = W \log_2(1 + S/N)\) 限制，信噪比不可能任意提高（信号功率不能无限大，热噪声永远存在）。
      • 区别与公式：码元/秒（波特 Baud）是每秒传输的信号波形（码元）个数；比特/秒（\(\text{bit/s}\)）是每秒传输的二进制信息量。若1个码元可表示 \(M\) 种离散状态（即携带 \(\log_2 M\) 比特），则 \(\text{比特率 } R = \text{波特率 } B \times \log_2 M\)。

    第3章（2题）

    1. 3-04 数据链路层的三个基本问题（封装成帧、透明传输和差错检测）为什么都必须加以解决？（官方大纲三(一)~(三)）
    2. 【底层逻辑】：物理层只管传 0101 比特流，既不知道哪儿是一句话的开头结尾，也会因为网线干扰传错比特。

    3. 【采分关键词】：

      • ①封装成帧：在一段数据前后分别添加首部和尾部（帧定界符），接收端才能从比特流中识别出一帧的开始和结束。
      • ②透明传输：若数据部分恰好出现与帧定界符相同的二进制编码（如 01111110），接收端会误认为帧提前结束而截断丢弃；必须用字节填充（PPP）或零比特填充（HDLC：连续5个1后插0）解决。
      • ③差错检测：实际通信链路都不是理想的，比特传输会产生误码，必须通过 CRC 循环冗余检验 检测出有差错的坏帧并直接丢弃，防止将错误数据递交网络层。

    4. 3-29 以太网交换机有何特点？用它怎样组成虚拟局域网 VLAN？（官方大纲三(八)1,2，2026-大3 原题考点！）

    5. 【底层逻辑】：集线器（Hub）是所有人共用一条大喇叭（同属一个冲突域），而交换机给每个端口配了独立通道和转发表；但交换机默认会把广播帧发给所有人，为了防止广播风暴，就在帧头里插个4字节的部门牌号（VLAN Tag），只有牌号相同的人才能收到广播。
    6. 【采分关键词】：
      • 交换机（与透明网桥）特点：以太网交换机实质是一个多端口的透明网桥，工作在数据链路层（MAC子层）；支持多对端口同时全双工、无碰撞通信，每个端口独享带宽；基于 MAC地址自学习算法（①逆向学习源MAC与接收端口写入转发表；②查表转发目的MAC：表中有且不同端口则单播转发、同端口则丢弃过滤、表中无则向除接收端口外所有端口泛洪广播；③老化机制超时清除） 存储转发帧；能隔离冲突域，但不能隔离广播域。
      • 组成 VLAN 方法：在交换机上将局域网内的站点从逻辑上划分为多个与物理位置无关的虚拟工作组（每个 VLAN 是一个独立的广播域，既隔离冲突域又隔离广播域）；当跨交换机干道链路（Trunk）传输时，交换机将标准以太网 802.3 帧转换为插入 4字节 VLAN 标记（含12位 VID）的 802.1Q 帧，到达目的交换机后再剥离标记还原为 802.3 帧交付主机。

    第4章（8个核心点，覆盖9题）

    1. 4-01 网络层向上提供的服务有哪两种？试比较其优缺点。（官方大纲二(一)5，2025-选24 原题）
    2. 【底层逻辑】：到底谁来干“保证可靠、按序到达”的苦活？电信网认为应该由网络里面的交换机干（虚电路服务）；互联网先驱认为路由器只管闭着眼往前扔包（数据报服务），可靠的苦活全交给两头的电脑（TCP）自己干。

    3. 【采分关键词】：

      • 虚电路服务（面向连接）：通信前先建立逻辑连接（虚电路 VC），分组只携带短虚电路号按固定路径顺序到达，中间节点需保存连接状态表。优点是分组首部短、按序到达；缺点是路由器复杂、某节点故障则所有经过该节点的虚电路均中断。
      • 数据报服务（无连接，互联网 IP 采用）：网络层向上只提供简单灵活、无连接的、尽最大努力交付（Best-Effort）的数据报服务。每个分组携带完整的目的 IP 地址独立选路，可能出错、丢失、重复或乱序到达。优点是网络造价低、路由器不保存连接状态、网络生存性极强；可靠传输由端系统的运输层（TCP）负责。

    4. 4-03 作为中间设备，转发器、网桥、路由器和网关有何区别？（官方大纲二(三)、三(八)、四(七)）

    5. 【底层逻辑】：所处的协议层越高，看得懂的包头越深，隔离的范围越大。

    6. 【采分关键词】：

      • 转发器（中继器 Repeater / 集线器 Hub）：物理层，对弱化的比特信号进行再生放大和转发，既不隔离冲突域，也不隔离广播域。
      • 网桥（Bridge / 局域网交换机 Switch）：数据链路层，根据 MAC 地址存储转发帧，隔离冲突域，不隔离广播域。
      • 路由器（Router）：网络层，根据目的 IP 地址查路由表转发分组，既隔离冲突域，又隔离广播域。
      • 网关（Gateway）：网络层以上，用于不同体系结构或高层协议之间的转换。

    7. 4-07 试说明 IP 地址与 MAC 地址的区别。为什么要使用这两种不同的地址？（2025-大2、2026-大4 连考两年大题！）

    8. 【底层逻辑】：MAC 地址是人的“身份证号”（走到哪都不变，但邮递员光看身份证号不知道你在哪个省哪个市）；IP 地址是“省/市/街道邮政编码”（方便全国邮局分拣路由，但到了最后一个小区门口，必须靠 ARP 问出这户人家的身份证号 MAC 才能把信塞进信箱）。

    9. 【采分关键词】：

      • 结构与层次区别：MAC 地址是平面结构（48位，固化在网卡 ROM 中，与地理位置无关，无法聚合）；IP 地址是层次结构（网络前缀 + 主机号，与所连接的网络拓扑相关，便于路由器按网络前缀聚合路由表，缩小路由表规模并屏蔽底层异构网络硬件差异）。
      • 作用层与转发变化规律（必背）：IP 地址工作在网络层，负责端到端的逻辑寻址；MAC 地址工作在数据链路层，负责同一局域网（单跳链路）内的物理帧交付。在跨多个路由器转发过程中（无 NAT 时），IP 数据报的源 IP 和目的 IP 全程保持不变；而数据链路层帧的源 MAC 和目的 MAC 每经过一跳路由器都会被重新改写封装一次！

    10. 4-10 当某个路由器发现一个 IP 数据报的首部检验和有差错时，为什么采取丢弃的办法而不是要求源站重传？计算首部检验和为什么不采用 CRC 检验码？

      • 【底层逻辑】：连信封上的字都模糊出错了，信封上写的“寄件人地址（源IP）”很可能也是错的，找谁重传去？而且路由器每秒要改几百万个包的 TTL，用 CRC 太慢了。
      • 【采分关键词】：①为什么不要求重传：首部出错时，其中的源 IP 地址字段本身可能已经损坏，路由器无法得知正确的源站地址；且 IP 层本身是无连接不可靠服务，差错重传由端系统的运输层（TCP）负责。②为什么不用 CRC：路由器每转发一跳，都要将 IP 首部中的 TTL（生存时间）减 1，因此每跳都必须重新计算首部检验和；不检验数据部分且采用简单的 16位二进制反码求和（而非复杂的 CRC），是为了简化路由器计算开销，加快分组转发速度。

      • (2) 不需要发 ARP 请求的情况：①源主机的 ARP 高速缓存中已经存在该目的 IP 对应的 MAC 映射记录；②发送的是广播分组（目的 MAC 直接填全 1，即 FF-FF-FF-FF-FF-FF）；③使用的是点对点链路（如 PPP 链路），无需使用 MAC 地址。

    1. 4-42 什么是 NAT？什么是 NAPT？NAT 的优点和缺点有哪些？NAPT 有哪些特点？（官方大纲四(三)2，2025-选10 原题考点）

      • 【采分关键词】：
      • 定义与特点：NAT（网络地址转换）将专用网内部的本地私网 IP 转换为全球合法的公网 IP；NAPT（网络地址与端口转换）在转换 IP 地址的同时还结合运输层端口号进行转换，使内部多台拥有不同私网 IP 的主机能够共同复用同一个全球公网 IP 地址同时上网。
      • 关键技术坑点（必记）：NAPT 重写源 IP 和源 TCP/UDP 端口号后，必须同时重新计算 IPv4 首部检验和与 TCP/UDP 检验和（因为 TCP/UDP 检验和覆盖了包含源/目的 IP 的伪首部）。
      • 优缺点：优点是极大节省了合法的全球 IPv4 公网地址，且隐藏了内网拓扑提高安全性；缺点是通信必须由专用网内部主机主动发起（外网无法主动找内网主机建立连接），且路由器需查看并修改运输层端口，破坏了网络分层的独立性与端到端透明性。

    2. 4-59 从 IPv4 过渡到 IPv6 的方法有哪些？（官方大纲四(四)）

      • 【采分关键词】：①双协议栈（Dual Stack）：一部分主机或路由器同时装有 IPv4 和 IPv6 两个协议栈，根据通信对象灵活使用 IPv4 或 IPv6 地址；②隧道技术（Tunneling）：在 IPv6 分组进入 IPv4 网络时，将其封装成为 IPv4 数据报的数据载荷部分（即 IPv4 首部 + IPv6 数据报），使 IPv6 分组能穿过中间的 IPv4 网络，到达另一端后再拆去 IPv4 首部还原出 IPv6 分组。

    1. 1-17（发送时延 vs 传播时延基础计算）
    2. 题目要点：距离 \(D = 1000\text{ km}\)，传播速率 \(v = 2 \times 10^8\text{ m/s}\)。求：(1) 数据长 \(10^7\text{ bit}\)、速率 \(100\text{ kbit/s}\)；(2) 数据长 \(10^3\text{ bit}\)、速率 \(1\text{ Gbit/s}\) 时的发送时延和传播时延。

    3. 开袋即食算式与答案：

      • 传播时延只看距离和光速，两种情况完全相同：$\(t_{\text{prop}} = \frac{1000 \times 10^3\text{ m}}{2 \times 10^8\text{ m/s}} = 5 \times 10^{-3}\text{ s} = 5\text{ ms}\)$
      • (1) 发送时延：$\(t_{\text{trans1}} = \frac{10^7\text{ bit}}{100 \times 10^3\text{ bit/s}} = 100\text{ s}\)$（此时发送时延占绝对主导）。
      • (2) 发送时延：$\(t_{\text{trans2}} = \frac{10^3\text{ bit}}{10^9\text{ bit/s}} = 10^{-6}\text{ s} = 1\ \mu\text{s}\)$（此时传播时延 \(5\text{ ms}\) 远大于发送时延 \(1\ \mu\text{s}\)）。

    8. 题目要点：A向B发 \(10^7\text{ bit}\) 报文，中间经2个节点交换机（即共 3段链路），每段链路速率 \(R = 2\text{ Mbit/s}\)，忽略传播、处理和排队时延。(1) 采用报文交换；(2) 划分为 \(1000\) 个等长分组（每个分组 \(10^4\text{ bit}\)）流水线发送。
    9. 开袋即食算式与答案（背熟流水线公式）：
      • (1) 报文交换：整报在1段链路上的发送时延 \(T = \frac{10^7\text{ bit}}{2 \times 10^6\text{ bit/s}} = 5\text{ s}\)。

      • (2) 分组交换流水线：单个分组在1段链路上的发送时延 \(t = \frac{10^4\text{ bit}}{2 \times 10^6\text{ bit/s}} = 5 \times 10^{-3}\text{ s} = 5\text{ ms}\)。
