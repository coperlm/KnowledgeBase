    816-初步

    【零、 卷面结构与 120-130 分失分红线控制】 1. 试卷结构（满分 150 分，考试时间 180 分钟）： - 单项选择题：40 题 x 2 分 = 80 分（计网 24 题共 48 分，题号 1-24；数据结构 16 题共 32 分，题号 25-40）。 - 综合应用题：8 题 = 70 分（计网 5 题共 42 分，题号 41-45；数据结构 3 题共 28 分，题号 46-48，其中仅 1 道为算法代码题占 10 分，其余 2 道为手工模拟与计算题占 18 分）。 2. 目标得分与容错红线（总失分必须严格控制在 20 至 30 分以内）： - 单项选择题（80 分）：保底 64 分（最多错 8 题），冲刺 68-70 分（错 5-6 题以内）。 - 计网综合大题（42 分）：保底 34 分，冲刺 36-38 分（5 道题均为分步踩点给分，每小问 2-3 分）。 - 数据结构应用大题（18 分）：保底 15 分，冲刺 16-17 分（2 道手工画图/列表计算题，接近零失误）。 - 数据结构算法代码题（10 分）：保底 7 分（写出设计思想 2 分 + 暴力解代码 4 分 + 复杂度 1 分），冲刺 9-10 分（命中 408 原题或写出空间换时间最优解）。

    一、 谢希仁《计算机网络（第8版）》精准使用方法（三类分流法，严禁盲目通刷） 必备工具：《谢希仁第8版教材》 + 《计算机网络释疑与习题解答》（官方配套课后题答案）。 核心原则：你已有 408 选择题一刷基础，严禁从第 1 页逐字通读谢书正文，严禁通做全书 367 道课后题！将全书拆分为“增量独有模块”与“第1-6章主干模块”两套手法处理：

    手法一：谢书“增量独有模块”（先精读指定正文，再拿《习题解答》当政治题直接读背） 此部分为 408 不考、但 816 必考的独有增量。课后题以概念、流程说明、协议分工辨析为主，不要花时间自己从零默写，直接拿着《习题解答》用荧光笔划出采分词熟读，达到“改成单选能秒选、出在大题最后一小问能写 2 句话拿满分”的标准：

    [ ] 1. 第 7 章《网络安全》（7.1 至 7.6 节全文 + 7.7 节核心概念，课后题全看）： - 安全威胁分类：被动攻击（截获、流量分析，不破坏数据，重在加密预防） vs 主动攻击（篡改、伪造、拒绝服务 DoS/DDoS、重放攻击，重在检测与恢复）。 - 对称密码体制（DES、3DES、AES）：加解密密钥相同；运算快、效率高、适合加密海量数据；但密钥分发难、管理复杂、无法实现数字签名（无法防抵赖）。 - 公钥密码体制（RSA、ECC）：公钥公开，私钥保密；保密通信用“接收方公钥加密、接收方私钥解密”（对应习题 7-08）；数字签名与认证用“发送方私钥签名、发送方公钥验证”；缺点是计算慢。 - 密码散列函数（MD5、SHA-1、SHA-256）：单向不可逆、抗碰撞、雪崩效应，生成固定长度报文摘要。 - 数字签名 5 步标准流程（必背）：(1)发送方 A 对明文算 Hash 摘要；(2)A 用自己私钥加密摘要得数字签名，与明文同发给 B；(3)B 用 A 的公钥解密签名还原摘要 1；(4)B 对收到的明文重算 Hash 摘要 2；(5)对比摘要 1 与摘要 2，一致则证明完整性、认证 A 身份且不可抵赖。 - 数字证书与 CA：CA 用自身私钥对用户公钥及身份信息签名颁发证书，解决公钥归属真伪问题。 - 防火墙分类：分组过滤路由器（工作在网络层/传输层，按源/目的 IP、协议类型、端口、TCP 标志位过滤，快但看不懂应用层语义） vs 应用级网关/代理防火墙（工作在应用层，充当代理深度审查 HTTP/FTP 内容，安全但时延大）。 - 补充 7.7 节 IPsec 与 TLS（2025 真题已考）：掌握 IPsec 隧道模式（封装整个原 IP 分组）、安全关联数据库 SAD 与安全策略数据库 SPD、ESP 协议利用递增序号及滑动接收窗口防重放（注意：仅凭序号不能防密文篡改，防篡改仍需完整性认证 MAC，对应 2025-选20）；掌握 HTTPS 即在 HTTP 下层采用 TLS 经身份认证建立会话密钥后加密并保护完整性（对应 2025-大4 第4问）。

    [ ] 2. 第 8 章《互联网上的音频/视频服务》（8.1 至 8.3 节流媒体全文，课后题全看）： - 传输特征：对偶尔误码和丢包容忍度高，但对时延和时延抖动（Jitter，相邻分组经历时延不同导致到达间隔不均匀）高度敏感。 - 播放端缓冲区机制：接收端设置缓冲区暂存分组一定时间后再匀速输出播放，平滑时延抖动，消除卡顿。 - 流式存储媒体与元文件（Metafile）：边下载边播放；浏览器先向 Web 服务器下载微小的元文件，调用本地播放器，再由播放器直接与媒体服务器建立流媒体连接。 - 三大协议分工（高频考点）： (1) RTSP（实时流协议）：应用层控制协议，充当“多媒体遥控器”，只管会话状态控制（Play 播放、Pause 暂停、Teardown 关闭、快进），自身不传媒体数据，底层可基于 TCP 或 UDP。 (2) RTP（实时传输协议）：运行在 UDP 之上，负责封装音视频数据；首部含“序号”（检测丢包与恢复分组次序）和“时间戳”（标记媒体采样时间以恢复同步播放，对应习题 8-12）。 (3) RTCP（实时传输控制协议）：与 RTP 配合的监控协议，周期性发送控制分组反馈服务质量（丢包率、时延抖动、RTT），供应用层动态调整编码速率。

    [ ] 3. 第 6 章应用层 3 个单列协议（精读正文 + 必看对应课后题）： - 6.3 节 TELNET（远程终端协议）：C/S 模式，TCP 端口 23；核心为网络虚拟终端 NVT（客户端将本地键盘输入转为 NVT 标准格式发给服务器，服务器再将 NVT 转为服务器 OS 内部格式，屏蔽异构系统终端差异）。 - 6.8 节 P2P 应用工作方式： (1) BitTorrent 体系：种子文件（.torrent，含文件分块哈希值及 Tracker 地址）、Tracker 跟踪服务器（维护活跃节点 IP/端口列表帮节点找对等方，不传实际文件）、最稀缺优先策略（Rarest First，优先下载副本最少的块）、针锋相对策略（Tit-for-Tat，优先给向自己提供上传带宽的节点提供下载）。 (2) P2P 与 C/S 文件分发最短时间计算（对应习题 6-51）：设文件大小 F，服务器上传速率 us，N 个对等方每个下载速率 di（最小为 dmin）、上传速率 ui。则 C/S 最短时间 = max(NF/us, F/dmin)；P2P 最短时间 = max(F/us, F/dmin, NF/(us + 所有 ui 之和))。 - 6.9 节 SNMP（简单网络管理协议）：基于 UDP，管理站端口 162（接收 Trap 告警），代理端端口 161（接收请求）；五大功能域（故障管理、配置管理、计费管理、性能管理、安全管理）；三大构件（SMI 管理信息结构：定义命名与语法规则；MIB 管理信息库：树状结构存放被管变量；SNMP 报文协议）；三大操作原语（Get-Request 读取、Set-Request 写入设置、Trap 代理端突发异常时主动异步告警）。

    [ ] 4. 第 3 章与第 1 章增量细节（精读正文 + 对应课后题）： - HDLC 协议：面向比特的同步链路层协议；标志字段 Flag 固定为 01111110；零比特填充法（发送端连续 5 个 1 后强制插 0，接收端连续 5 个 1 后自动删 0）；三种帧类型及前两位编码：信息帧 I 帧（第 1 位为 0，传用户数据，带发送序号 N(S) 和接收序号 N(R)）、监控帧 S 帧（前两位 10，无数据字段，用于流量和差错控制，如 RR 接收就绪、RNR 接收未就绪、REJ 拒绝重传）、无编号帧 U 帧（前两位 11，不带序号，用于链路建立拆除与控制，如 SABM、DISC）。 - 透明网桥（Bridge）：工作在 MAC 子层，隔离冲突域但不隔离广播域，交换机实质是多端口网桥；自学习算法三步标准话术：(1)逆向学习（收到帧记录源 MAC 与接收端口到转发表，启动/重置老化定时器）；(2)查表转发（查目的 MAC，找到且端口不同则单播转发，端口相同则丢弃过滤，未找到则向除接收端口外所有端口泛洪广播）；(3)老化机制（TTL 超时未更新自动清除）。 - 第 1 章 1.4 节标准化：RFC 成为正式标准阶段（因特网草案 Internet Draft -> 建议标准 Proposed Standard -> 因特网标准 Internet Standard）；组织职责：IETF（制定 RFC）、ISO（提出 OSI）、ITU-T（电信标准）、IEEE（制定 802 局域网标准）、W3C（万维网标准）。

    手法二：谢书“第 1 至 6 章主干模块”（不看正文，用《习题解答》逆向三桶过滤） 直接翻开每章课后题与《习题解答》，按以下三个桶分流处理，只有遇到卡壳才翻回谢书正文看对应两页：

    【第一桶：必动笔算！全书严选约 45 道经典计算/图表母题】 [ ] 第 1-2 章： - 存储转发与分组流水线时延计算（对标 2025-大1：掌握首分组到达时间 = 2发送时延 + 2传播时延 + 交换机处理时延；全部 M 个分组流水线到达时间 = 首分组到达时间 + (M-1)单个分组瓶颈发送间隔；以及不分组整报转发耗时对比）。 - 物理层码元与比特率换算（对标 2025-选2）：若有 K 种幅相状态，每码元携带 log2(K) 比特，比特率 R = 波特率 B * log2(K)。 - 香农公式与信噪比 dB 换算（对标谢书习题 2-08）：信噪比(dB) = 10 * log10(S/N)，如 30 dB 对应 S/N = 1000，极限容量 C = W * log2(1 + S/N)。 - 传输介质衰减最大工作距离（对标谢书习题 2-11）：最大距离 = 允许最大总衰减(dB) / 单位长度衰减(dB/km)，如 20 / 0.7 = 28.6 km。 - CDMA 码片序列正交内积计算（发送 +1 比特发原码片，发送 0 比特发反码，接收端用规格化内积还原）。 [ ] 第 3 章： - CRC 循环冗余校验手算模 2 除法，并明确 CRC 是检错码而非纠错码，余数为 0 仅代表本次未检出差错，若差错多项式恰好为生成多项式倍数仍会漏检（对标谢书习题 3-07）。 - CSMA/CD 争用期（2传播时延）与最短有效帧长计算。 - 802.11 无线局域网 DCF 机制（对标 2025-选22、选23）：SIFS 短帧间间隔最短（保障 ACK、CTS 等控制帧最高优先级先行回应），普通新数据帧需等待 DIFS 后再走退避算法；收到 RTS/CTS 等有效预约信息后，站点 NAV（网络分配向量）为正值时，按虚拟载波侦听必须等待预约结束，不能仅凭物理信道空闲就抢发新普通数据帧。 - 以太网交换机/透明网桥自学习转发表填写与转发端口列表题（谢书第 3 章课后必算 2 道）。 [ ] 第 4 章（网络层占分极高，必须逐题算透）： - IPv4 数据报分片计算（对标谢书习题 4-20）：总长 4000B（首部 20B，数据 3980B），MTU=1500B，则每片最大数据载荷 = 1480B（必须为 8B 整数倍）；前两片数据各 1480B，共 2960B，故第 3 片片偏移字段值 = 2960 / 8 = 370。 - CIDR 精确路由聚合（对标谢书习题 4-22）：将连续 4 个 /24 地址块（如第三字节 132、133、134、135，二进制前 6 位相同）聚合为 /22。 - 等长/变长子网划分与路由器路由表编写（对标 2025-大3）：如将 172.16.10.0/24 等分为两个满足 >=120 台主机的子网，即两个 /25（掩码 255.255.255.128），每个子网可用 IP 126 个，扣除 1 个网关接口 IP 后剩 125 个普通主机 IP；熟练写出路由器路由表中的“直连网段（直接交付）”与“Internet 默认路由（目的网络 0.0.0.0/0，掩码 0.0.0.0，下一跳指向邻居网关 IP）”。 - 跨子网 ARP 与帧封装变化（对标 2025-选17、2025-大2）：ARP 广播严禁跨路由器转发；访问本网段设备（如同网段本地 DNS）直接 ARP 广播解析其 MAC；访问外网 Web 服务器时，主机用 ARP 解析的是本地默认网关 G 的 MAC，发出的 TCP SYN 报文源 IP 为主机、目的 IP 为远端 Web 服务器，但本地以太网帧的目的 MAC 填默认网关 G 的接口 MAC。 - 输入队列逐字节公平排队（Round-Robin）输出顺序计算（对标 2025-选19）：多个输入队列按 1->2->3 固定循环每次各读 1 字节，同一队列先读完前一个包再读下一个包，算出每个包读完最后一字节所在的虚拟轮次，按完结轮次先后（同轮次按端口号 1->2->3）排出进入输出队列的分组顺序。 - RIP 距离向量路由表更新算法（谢书第 4 章必算 3 道大题：收到邻居 X 发来的 RIP 报文后，先将所有距离加 1、下一跳全改为 X，再按“原表无则添加、原表下一跳同为 X 则无条件替换、原表下一跳不同则距离更小才更新”逐行核对）。 - BGP 边界路由算法（路径向量算法 Path Vector）：理解为何自治系统 AS 之间不能用距离向量或链路状态（网络规模过大、各 AS 安全与商业策略不同），BGP 如何通过 AS-Path 列表防环并实现策略路由。 [ ] 第 5-6 章（传输层与应用层核心计算）： - TCP 三次握手与四次挥手序号计算（对标 2025-选21、谢书习题 5-62）：不带数据的 SYN 段和 FIN 段均各消耗 1 个序号（客户端发 SEQ=x 的 SYN，服务端同意连接回复 SYN=1, ACK=1, 确认号 ack=x+1；收到期待的 SEQ=901 且 FIN=1 的段，返回的确认号应为 902）。 - TCP 字节序号、段长度与乱序缓存累计确认（对标 2025-大5）：给三段起始序号 500、600、800 及全部收齐后的确认号 900，算各段长度（600-500=100B, 800-600=200B, 900-800=100B）；若第 2 段丢失，收到第 1 段回 ACK=600；随后收到第 3 段（800-899）虽乱序缓存，但因缺 600-799，按累计确认仍回重复 ACK=600；待重传第 2 段补齐后直跳 ACK=900。 - TCP 拥塞控制四大算法（慢开始、拥塞避免、快重传、快恢复）cwnd 与 ssthresh 随传输轮次变化的折线图计算（谢书第 5 章课后必算 3 道），以及谢书标准 RTO 加权平均公式（RTTs、RTTd 与 RTO = RTTs + 4RTTd）。 - TCP 首部十六进制拆解与 HTTP 报文分析（对标 2025-大4）：TCP 首部前 4 字节网络字节序（大端序）前 2 字节为源端口、后 2 字节为目的端口（如 c3500050 中，0xC350 = 124096 + 3256 + 516 = 50000，0x0050 = 80）；识别 HTTP/1.1 请求行（GET 方法、请求资源 /index.html），明确 Connection: keep-alive 表示保持/复用当前 TCP 连接以减少反复握手开销。 - DNS 递归与迭代查询流程（对标 2025-大2）：主机向本地 DNS 发递归查询，本地 DNS 向根、顶级域（.cn）、权威域名服务器发迭代查询，通常基于 UDP 端口 53（区域传送或超长响应等必要时用 TCP 53）。

    【第二桶：用眼睛扫读答案！抓反直觉单选坑点（全书约 70 道，重点记以下真题/替补题题眼）】 [ ] 1. 数据报 vs 虚电路（习题 4-01）：数据报服务独立携带完整目的地址、独立选路、可能乱序到达、不保证可靠交付；虚电路建立逻辑连接与路径状态，但不等于专用物理电路。 [ ] 2. NAPT 校验和更新（习题 4-42）：NAPT 设备修改 UDP 数据报的源 IP 地址和源 UDP 端口号后，不仅要重算 IPv4 首部检验和，还必须重算 UDP 检验和（因为 UDP 检验和计算覆盖了包含源/目的 IP 地址的 12 字节伪首部）。 [ ] 3. UDP 全零校验和规则（习题 5-51）：IPv4 中若发送方启用了 UDP 检验和，但按反码算术运算算出的检验和结果恰好为全 0（0x0000），发送时必须改填为全 1（0xFFFF），因为 UDP 首部检验和字段为全 0 专用于表示“发送方未计算/未使用检验和”。 [ ] 4. TCP 连接唯一标识（习题 5-09）：一条 TCP 连接由两端套接字（Socket）即四元组（源 IP、源端口、目的 IP、目的端口）唯一标识。 [ ] 5. DHCP 首次获取地址四步交互（习题 6-32）：DORA 顺序即 DISCOVER（广播发现） -> OFFER（提供租约） -> REQUEST（广播请求选定租约） -> ACK（确认）。 [ ] 6. MIME 与 SMTP（习题 6-25）：SMTP 本身仅面向 7 位 ASCII 文本，MIME 通过 base64 等编码方式把二进制附件转为文本传输（注意：base64 是编码，绝不是加密！）。 [ ] 7. traceroute 推断边界（2025-选16）：一次 traceroute 成功仅证明测试当时的探测包与中间路由器返回的 ICMP 超时报文路径畅通，不能推广保证路径上所有路由器的全部 ICMP 功能或所有应用业务永久正常。 [ ] 8. VLAN 与 802.1Q：虽未在 816 大纲单独列行，但包含在局域网交换机工作原理中，需掌握 VLAN 隔离广播域的作用及 802.1Q 帧插入 4 字节标记字段的跨交换机 Trunk 转发原理。

    3. 后 28 天策略：保持每天 2.5 - 3 小时专业课节奏，每周用 953 去 OS 真题或其它年份回忆重构卷做 2 次限时模考，重点抠大题步骤规范（如路由表必写默认路由 0.0.0.0/0、链表删除必写 free 且说明前驱指针不前移、算法题必写时间与空间复杂度），稳步冲刺 125-130+ 分，每天可匀出 30 分钟补强数学一。

    4. 【情况 B：Day 24 模考总分在 102 - 115 分之间（存在明显局部短板）】

    5. 诊断：大方向正确，但局部失血，立刻在最后 28 天执行靶向止损调仓：
    6. 若【计网单选题得分 < 36/48】：说明谢书课后题细节和增量概念不熟。后 28 天停止刷偏难大题，每天抽 90 分钟专门抱着《谢书习题解答》和《考纲差异文档》反复读背第 6/7/8 章问答及前 5 章单选易错点（如 UDP 全 0 校验和发全 1、NAPT 改校验和、802.11 NAV 等），15 天即可追回 8-10 分。
    7. 若【常规计算与手工画图大题丢分严重（如时延算错、子网掩码写错、BST 删错、AOE 算错 vl）】：说明眼高手低、动笔太少。后 28 天每天只拿空白 A4 纸，把计网 7 类母题（时延、ARP+DNS、子网+路由表、RIP 更新、IP 分片、TCP 序号/拥塞控制、HTTP+端口）和数据结构 10 类画图题（KMP、哈夫曼、树转换、DFS/BFS、最小生成树、Dijkstra、AOE 关键路径、BST/AVL/B树、散列表 ASL、排序）每类再亲手算 3 遍，把计算准确率拉到 95% 以上。

    8. 若【算法代码题（第 46 题，10 分）拿不到 4 分】：后 28 天彻底放弃钻研复杂最优算法，启动“代码暴力拿分止损法”——考场上无论遇到什么链表或树的代码题，第一步先用 3 行文字清楚写出暴力解法的设计思想（稳拿 2 分）；第二步直接写最稳妥的“开 seen[n+1] 辅助数组空间换时间”或“将链表数据全部读入一维数组 A[]，在数组内用双重 for 循环处理完后再重连链表”的代码（稳拿 4-5 分）；第三步写出时间与空间复杂度 O(...)（稳拿 1-2 分），保底锁死 7-8 分！

    9. 【情况 C：极端预警（若在 Day 12 中期测试就发现每天 3 小时完不成定量任务）】

    10. 早期止损方案：如果在 Day 12 发现做 408 数据结构压轴算法题耗时过长（例如一道题卡 1 小时），导致谢书看不完，从 Day 13 起立刻砍掉 2020-2024 年 408 最难的算法大题，只背熟 2009-2019 年最经典的链表与数组算法题（特别是 2015 年链表去重等母题），把时间 100% 优先保给“谢书课后题 + 考纲增量模块 + 王道常规画图大题”，先锁死卷面 140 分常规题目的高得分率！
