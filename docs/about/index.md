# 关于知识库

欢迎来到 Coperlm 的芝士库。

这里是一个持续整理中的个人知识库，用来保存学习过程中积累的概念、推导、实践记录和阶段性总结。内容会随着学习不断补充和修订，因此它更像一座正在生长的知识花园，而不是一本一次完成的书。

## 这里有什么

知识库目前主要分为三个方向：

- [自然与应用科学](../science/index.md)：数学、计算机科学、密码学、人工智能等内容。
- [人文与社会科学](../humanities/index.md)：语言、宗教、社会和人文相关内容。
- [艺术与文化生活](../arts/index.md)：艺术、生活经验以及个人兴趣记录。

不同主题会按照内容继续细分。你可以从首页的分类树开始浏览，也可以使用站点搜索直接查找关键词。

## 知识库与博客

博客更适合记录正在发生的事情，文章通常按照时间和事件展开；知识库更适合保存可以反复查阅的内容，重点在于分类、关联和长期积累。

同一个主题可能先出现在博客中，经过学习、整理和验证后，再沉淀为知识库中的条目。这里的文章不一定代表最终结论，阅读时可以结合文中的来源、推导和上下文理解。

## 如何阅读

- 想浏览主题，可以从首页选择一个分类。
- 想查找具体概念，可以使用页面顶部的搜索功能。
- 想了解一篇文章所属的主题，可以查看页面上方的路径导航。
- 想继续深入，可以沿着文章中的相关链接和参考资料阅读。

知识库的页面会持续更新，部分内容可能仍在整理中。对于重要结论，建议同时查看文章给出的教材、论文或其他参考来源。

## 内容说明

这里的内容主要来自个人学习和实践记录，包含笔记、例题、代码、图表与阶段性思考。不同文章的详细程度和完成度可能不同：

- 有些文章是经过多次整理的长期笔记。
- 有些文章是刚开始形成结构的学习记录。
- 有些文章用于保存问题、想法或未来继续研究的线索。

如果你发现内容中的错误、过时信息或链接失效，欢迎通过 GitHub 提出反馈。
